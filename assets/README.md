# Thư mục Tài nguyên Hình ảnh (`assets/`)

Thư mục lưu trữ toàn bộ hình ảnh thiết kế, sprite nhân vật DiVA và ảnh câu hỏi cho dự án **DiVA Vision Explorer Quiz**.

## Cấu trúc thư mục
- `diva_character_blueprint.png` — Bản thiết kế chuẩn nhân vật DiVA, tỷ lệ, tư thế hành động & bảng màu chính thức.
- `diva_emotion_expressions.png` — Bộ 11 biểu cảm khuôn mặt của Tắc kè hoa DiVA (Việt–Anh).
- `diva_quiz_ui_mockup.png` — Bản mockup giao diện 4 màn hình chính (Welcome, Chặng 1 LOOK, Chặng 2 THINK, Chặng 3 CONNECT).
- `mascot/` — Chứa các ảnh sprite DiVA đã tách nền (WebP/PNG) dùng trực tiếp trong UI.
- `questions/` — Chứa ảnh gốc cắt từ Poster / e-Document Vision 2035 (phục vụ upload lên Supabase Storage `quiz-assets`).
